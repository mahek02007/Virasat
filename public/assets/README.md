## 📊 Image Specifications

### File Formats
- **JPG:** Photos, landscapes, food, monuments (smaller file size)
- **PNG:** Avatars, graphics with transparency, logos

### File Sizes (Target)
- **Avatars:** < 100 KB
- **Hero Images:** < 200 KB
- **Section Images:** < 150 KB
- **Total per region:** ~2-3 MB

### Optimization
Before adding images:
1. Resize to recommended dimensions
2. Compress using TinyPNG or similar
3. Convert to WebP (optional, for better compression)
4. Ensure good quality at compressed size

---

## 🎨 Image Quality Guidelines

### What Makes a Good Image:

✅ **High Resolution** - Sharp, clear, professional  
✅ **Good Lighting** - Natural, even, not too dark  
✅ **Cultural Accuracy** - Authentic representation  
✅ **Clean Composition** - Clear subject, no clutter  
✅ **Relevant Content** - Matches the section topic  

❌ **Avoid:**
- Pixelated/blurry images
- Stock photos that look generic
- Watermarked images (unless you have rights)
- Poor lighting or composition
- Culturally insensitive content

### Recommended Free Sources:
1. **Unsplash** - High-quality free photos

### Custom Photography:

### Attribution:
- Check license requirements
- Credit photographers when needed
