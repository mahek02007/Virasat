## 🔖 Key Tagging System Used Throughout

| Tag | Meaning |
|-----|---------|
| `[HIGH]` | Confirmed by authoritative/primary source |
| `[MEDIUM]` | Reputable secondary/academic source |
| `[LOW]` | Limited or conflicting evidence |
| `[HISTORICAL FACT]` | Verified historical record |
| `[RELIGIOUS BELIEF]` | Faith claim, not independently verifiable |
| `[MYTHOLOGICAL ACCOUNT]` | Mythology/sacred narrative |
| `[FOLK TRADITION]` | Oral/folk tradition |
| `[ORAL TRADITION]` | Passed down orally |
| `[SCHOLARLY INTERPRETATION]` | Academic analysis/interpretation |
| `[SOURCE DISAGREEMENT]` | Conflicting sources — both sides presented |
| `[TIME-SENSITIVE]` | Tourism/pricing/schedule data — verify before use |

## ⚠️ Known Gaps & Recommendations

1. **M4 Food module** is the most concise (4.3 KB) — consider expanding individual dish entries for the full 30+ dish database
2. **District-level granularity** in M1 uses summary format; some lesser-visited districts (Gadchiroli, Nandurbar, Hingoli) need fieldwork-based research
3. **Tribal community data** for some smaller communities (Kolam, Andh, Pardhi) is sparse — Anthropological Survey of India consultation recommended
4. **Image/media rights** — all multimedia requirements documented in M8 (Part 38); no images have been cleared for use — individual licensing required
5. **Tourism data** — all marked `[TIME-SENSITIVE]`; integrate with live MTDC API for real-time data
